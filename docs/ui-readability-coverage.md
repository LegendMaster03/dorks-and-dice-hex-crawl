# UI Readability Coverage Matrix

This matrix records the presentation coverage for the comprehensive expedition readability pass. The current catalog contains **12 presets** and **19 authoring modules**. Presets remain compositions of generic modules; no presentation behavior branches on preset identity.

The layout follows the same design principle across authoring and play: compact aligned facts for scanable state, roster or ledger rows for repeated entities, progress indicators only when authoritative bounds exist, stage sequences for journeys, and focused resolution blocks for actions that require a decision.

## Movement composition contributor coverage

The focused movement ledger is generic over the authoritative contributor projection and supports every current contributor kind: Participant, Mount, Vehicle, Load, TravelMode, TerrainRoute, Environment, PersistentEffect, and DmOverride. Each row shows source, operation, value or symbolic value, and whether the contributor applied. The summary distinguishes authoritative base/reference use, unresolved inputs, retained but unapplied contributors, and applied DM overrides.

## Representative visual review scenarios

The existing Phase 15 rendered review matrix remains the reproducible visual harness. This pass adds a dedicated **movement-composition** scenario containing all nine movement contributor kinds. Existing scenarios cover procedure Compact/Advanced/JSON, spatial travel with no course and persisted course, partial progress, navigation and boundary resolution, encounter resolution, forced travel across participant/party/mount/vehicle scopes, effects, journey normal/pending/consequence states, abstract spatial play, standalone/nonspatial play, light/dark themes, embedded width, tablet, and narrow/mobile widths.

The matrix deliberately uses representative combinations instead of an exhaustive Cartesian product. Exact configuration remains available through Advanced/JSON and the reference's Exact parameter detail disclosure.
